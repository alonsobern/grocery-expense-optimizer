# Personal Grocery & Expense Optimizer

A simple, beginner-friendly Flask application to manage groceries and expenses.

## Project Structure

- `app.py`: Main entry point for the application.
- `templates/`: HTML files for the web pages.
- `static/`: CSS styling and images.
- `database/`: Placeholder for database files.

## How to Run

1.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

2.  **Run the application:**
    ```bash
    python app.py
    ```

3.  **Open in browser:**
    Go to `http://127.0.0.1:5000`
